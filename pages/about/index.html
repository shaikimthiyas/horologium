01 // THE ENGINEERING MANIFESTO

Why Time is Broken on the Web — And How We Solved It

Modern web software treats time as an afterthought. Browsers routinely sample non-monotonic system clocks that jump backwards on NTP step adjustments, break during daylight saving shifts, and leak geographic telemetry through invasive third-party IP lookups.

In 1759, carpenter and watchmaker John Harrison solved longitude at sea by inventing the H4 marine chronometer — a mechanical instrument so stable it operated as an autonomous sovereign reference. Horologium is the modern software heir to that philosophy.

Rather than trusting a single external server, Horologium implements Marzullo's Intersection Algorithm to query multiple Stratum-1 atomic reference clocks simultaneously, identify and discard statistical falsetickers, and lock onto verified consensus. When offset drifts, a continuous Linux adjtime-style slew controller gradually steers time back to atomic synchronization without ever allowing the client clock to tick backwards.

When network connectivity is completely severed, Horologium’s Progressive Web App engine transitions into sovereign flight mode, executing microsecond-level temperature-compensated crystal oscillator (TCXO) mathematical drift compensation.
