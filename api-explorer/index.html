● SNTP RFC 4330 / 5905

Bidirectional Simple Network Time Protocol socket. The client transmits an SNTP_PROBE frame with transmit timestamp t1; the server responds with receive timestamp t2 and transmit timestamp t3.

// Bidirectional SNTP Math: RoundTripDelay (delta) = (T4 - T1) - (T3 - T2) ClientClockSkew (theta) = ((T2 - T1) + (T3 - T4)) / 2 OneWayLatency (tau) = delta / 2 AtomicTime = ClientLocalTime + theta
